Uso de cámara externa (iPhone)
Para este paso hay una opcion para usar la cámara de un celular conectada por USB
a la computadora para simular la camara de la laptop, mediante alguna aplicación (En nuestro caso se instalo Camo) como puente. El iPhone actúa como sensor óptico del enlace; el procesamiento y la decodificación se realizan en Python sobre la computadora.

El cable USB es una herramienta.
